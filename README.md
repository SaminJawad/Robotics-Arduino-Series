# Robotics Arduino Series

A growing collection of beginner-to-intermediate Arduino projects, from blinking LEDs to games and motor control. Every project has working code, a wiring table, a Wokwi simulation and a short explanation of how it works, so you can learn the logic instead of just copying a sketch.

## Getting Started

1. Install the [Arduino IDE](https://www.arduino.cc/en/software).
2. Open any project's `.ino` file in the Arduino IDE.
3. Select your board (Tools → Board → Arduino Uno) and port, then click **Upload**.

No hardware yet? Every project links to a Wokwi simulation you can run in the browser.

Each project folder contains:

```
project-name/
├── project_name.ino    Arduino sketch
├── README.md           Components, wiring, how it works
├── wiring.png          Wiring diagram
└── live.gif            Short demo
```
